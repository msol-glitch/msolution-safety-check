누구나QR을 찍으면 보이는 것

  1. 📢 대표 전달사항 — 제목을 누르면 자세히 보기. 언어 버튼(中文 · Tiếng Việt · ខ្មែរ · Indonesia · Русский)으로 번역을 볼 수 있습니다. 다 읽으면 확인했습니다를 누르세요.
  2. 오늘 우리 팀 안전 현황 — 순회점검 · 3정5행 · TBM을 했는지 보입니다.
  3. 오늘의 TBM 안전 주제 3개 — 라인별로 나옵니다. 크게·외국어를 누르면 큰 글씨와 내 나라 말로 볼 수 있습니다.
  4. 최근 14일 추이 그래프 — 파란 실선 = 종합 실시율, 주황 점선 = TBM 실시율.
QR을 찍으면 팀과 시각만 기록됩니다(발도장). 이름은 저장되지 않습니다.
QR은 휴대폰 기본 카메라로 찍어 주세요.

관리자처음 1번: 관리자 폰 등록

  1. 팀 QR을 찍고 화면 아래 관리자 메뉴 🔒로 내려갑니다.
  2. 관리자 번호를 넣고 이 휴대폰을 관리자 폰으로 등록을 누릅니다.
  3. 순회점검 · TBM · 3정5행 버튼이 나타납니다. 한 번 등록하면 4개 팀 QR 모두 관리자로 인식됩니다.
관리자 번호는 다른 사람에게 알려주지 마세요. 폰을 바꾸거나 잃어버리면 화면 맨 아래 등록 해제 후 대표에게 알려 주세요.

순회점검

  1. 순회점검 → 점검자 선택
  2. 항목을 누를 때마다 ✓ 양호 → ✗ 개선 필요 → – 해당없음 순서로 바뀝니다. 이상 없으면 모두 양호.
  3. 개선 필요는 내용을 꼭 적습니다. (조치관리에 자동 등록)
  4. 서명(하루 1번, 같은 날은 자동 사용) → 제출
각 팀 현장에서 제출해 주세요. 순회 실시는 이성희 과장 · 대표 중 1명 이상이면 됩니다. 근거 버튼을 누르면 법 조항을 볼 수 있습니다.

3정5행

  1. 3정5행 점검 → 점검자 이름 입력
  2. 항목 체크 (방법은 순회점검과 같음)
  3. 서명 필수 → 제출

관리자TBM (작업 전 안전회의) — 시작 → 마치기

① 모일 때

  1. QR → TBM → 라인 선택 → ▶ TBM 시작
  2. 시작 시각이 서버에 기록됩니다. 화면을 닫아도 됩니다.

② 진행 (권장 10분)

  1. 오늘의 주제 3개를 읽어 줍니다. (위험성평가에서 자동 선택)
  2. 외국인 직원에게는 크게 보여주기 → 언어 버튼을 눌러 보여 줍니다.

③ 끝나면

  1. QR → TBM 다시 들어가면 "진행 중"이 보입니다.
  2. 참석 인원 · 결근 인원(이름) · 의견 · 진행자 · 실제 끝난 시각 입력 → 서명 → TBM 마치기 · 제출
  3. 나온 기록번호(TBM-월일-라인-숫자)와 시간을 작업일보 TBM란에 적고, 직원들은 작업일보에 친필 서명합니다.
시작을 깜빡했으면 "시작을 못 눌렀어요"에서 실제 시작 시각과 사유를 넣으세요. 기록에 '수기'로 표시됩니다.
시간은 실제 시간 그대로 기록됩니다(10분으로 맞춰 적지 않습니다). 같은 라인은 하루 1번입니다. 다른 관리자 폰으로 마쳐도 됩니다.

자주 묻는 것

Q. 관리자 메뉴가 안 보여요

관리자 폰으로 등록해야 보입니다. 다른 앱(카카오톡 등)으로 QR을 찍으면 다시 등록해야 할 수 있어요. 기본 카메라로 찍으세요.

Q. 제출이 안 돼요

인터넷 연결을 확인하고 다시 누르세요. 그래도 안 되면 화면을 캡처해서 대표에게 보내 주세요.

Q. 번역이 이상해요

자동 번역입니다. 정확한 내용은 한국어 원문이 기준입니다. 이상한 표현은 반장에게 알려 주세요.

Q. 내 이름이 기록되나요?

QR 보기·확인은 이름 없이 팀과 시각만 남습니다. 점검·TBM은 관리자(진행자) 이름과 서명만 남습니다.

Q. 잘못 제출했어요

제출한 기록은 고칠 수 없습니다. 바로 다시 제출하고, 사유를 대표에게 알려 주세요.
